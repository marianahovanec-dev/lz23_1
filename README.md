🎯 Мета роботи
Оволодіти практичними навичками роботи в середовищі MS Visual Studio (С++/CLI) для розробки Windows Forms застосунків. Навчитися використовувати класи простору імен System::Drawing для створення графічних примітивів, налаштовувати компоненти Timer для реалізації простої анімації, а також застосовувати клас System::Media::SoundPlayer для інтеграції та відтворення мультимедійних аудіофайлів.

Опис роботи: Програма реалізує графічний інструмент для побудови геометричних фігур. На формі розміщено елемент ListBox для вибору типу фігури (Лінія, Прямокутник, Еліпс, Сектор, Зірка, Трикутник, Будиночок) та ComboBox для вибору кольору (червоний, синій, жовтий, чорний тощо). За допомогою класів Graphics, Pen (для малювання контурів) та Brush (для заливки) програма генерує обрану фігуру. Перед малюванням нової фігури робоча область автоматично очищується.

Опис роботи: Програма демонструє роботу з простою анімацією. Інтерфейс містить кнопки "Start" та "Stop", а також три компоненти PictureBox із завантаженими зображеннями. Кнопка "Stop" зупиняє всі таймери та приховує всі зображення.

Опис роботи: Створено інтерактивний аудіословник для вивчення 12 англійських слів на тему "Напої". Користувач обирає слово у списку ListBox. Відтворення аудіо здійснюється за допомогою об'єкта класу System::Media::SoundPlayer, який завантажує файл методом Load() та програє його через Play().

📝 Висновки
Під час виконання лабораторної роботи було успішно реалізовано три застосунки мовою С++/CLI у середовищі MS Visual Studio. Практично закріплено навички роботи з графічним простором імен System::Drawing (робота з координатами, об'єктами Pen та Brush), використання таймерів для синхронізації подій у часі (анімація) та інтеграції мультимедійних компонентів (аудіо у форматі .wav). Програми працюють стабільно, коректно обробляють вибір користувача та демонструють розуміння основних принципів об'єктно-орієнтованого програмування з графічним інтерфейсом.
